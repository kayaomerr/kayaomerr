# Featured Project

## ✈️ METAR Alert

Modern aviation weather application built for pilots and aviation students.

### Features

* Real-time METAR data
* Smart weather alerts
* Push notification system
* Airport-based subscription model
* Aviation-focused modern UI
* Real-time METAR decoding logic
* Flight condition evaluation system

### Infrastructure

* React Native + Expo
* Node.js + Express
* PostgreSQL + Prisma
* Railway Deployment
* RevenueCat Subscriptions
* Apple Sign In
* APNs Push Notifications
